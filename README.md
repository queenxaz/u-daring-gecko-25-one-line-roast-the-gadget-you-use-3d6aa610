cable — for the
[make.fun bounty](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
"One-Line Roast: The Gadget You Use Every Day" ($5 pot, top 3 paid).

## The entry

> My charging cable only works at one exact angle, so plugging in my phone every night feels like cracking a safe in the dark.

One line, 124 characters. The roast targets a daily gadget with a concrete,
specific gripe — the cable that only charges at one precise angle — and a
fresh comparison instead of the usual dead-battery complaint.

## How it works

`main.py` writes the line above to `/output/entry.txt`. It is fully
deterministic: no network, no randomness, no input files. It creates
`/output` if it is missing and never deletes it.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
